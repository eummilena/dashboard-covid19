# 🦠 Análise da COVID-19 no Brasil com Power BI

Dashboard interativo em Power BI para acompanhar a evolução da COVID-19 no Brasil, com indicadores de casos, óbitos, letalidade, testes e vacinação. Projeto final de conclusão do curso **[nome do curso]** – [instituição].

## 🎯 Objetivo

Transformar dados públicos da pandemia em informação clara, usando indicadores e visualizações que ajudem a entender a evolução da doença no país e a comparar os estados.

## 📊 Indicadores apresentados

- Total de casos
- Total de óbitos
- Taxa de letalidade
- Recuperados
- Testes realizados
- Total de casos por semana
- Top 5 estados com maior número de casos
- Vacinas e total de doses aplicadas
- Informações gerais sobre a COVID-19

## 🗂️ Fontes de dados

| Fonte | Formato | Link |
|-------|---------|------|
| covid19br (casos por estado) | CSV | [cases-brazil-states.csv](https://raw.githubusercontent.com/wcota/covid19br/master/cases-brazil-states.csv) |
| Our World in Data (COVID-19) | JSON | [owid-covid-data.json](https://raw.githubusercontent.com/owid/covid-19-data/master/public/data/owid-covid-data.json) |

Os dados são públicos e foram importados diretamente dos repositórios acima para o Power BI.

## 🛠️ Tecnologias

- **Power BI** – importação, modelagem e visualização dos dados
- **CSV e JSON** – formatos das bases utilizadas


## ▶️ Como visualizar

1. Baixe o arquivo [`nome-do-arquivo.pbix`](./nome-do-arquivo.pbix) deste repositório.
2. Abra no **Power BI Desktop** (gratuito para Windows).
3. Se necessário, clique em **Atualizar** para carregar os dados mais recentes das fontes.
